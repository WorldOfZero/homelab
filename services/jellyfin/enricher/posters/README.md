# Collection posters

`make_posters.py` renders a poster for each collection from `template.svg` into
`../collection-images/`, which the enricher uploads as the collection's primary image (see
`../README.md`).

```bash
cd services/jellyfin/enricher/posters
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python make_posters.py --preview --watch      # iterate: see below
.venv/bin/python make_posters.py --all --out preview    # every collection, to check the defaults
.venv/bin/python make_posters.py                        # write to ../collection-images/
```

To iterate on the design, run `--preview --watch` and open `preview/index.html` in a browser.
It renders the posters in `posters.yaml` plus its `preview:` list of awkward titles, and renders
them again each time you save `template.svg`, `posters.yaml` or an icon. The page reloads itself
every 3 seconds. Restart the command after editing `make_posters.py`.

`preview/` is ignored by git. Rendering needs no system packages: `resvg_py` bundles the renderer,
and the fonts are in `fonts/`.

## What to change where

- **`template.svg`**: the layout shared by every poster: background, glow, frame, label and
  rule. Open it in a browser or editor to see it; placeholders such as `$accent` are filled per
  poster. `--svg` also writes each filled-in SVG next to its poster.
- **`make_posters.py`**: the title box (`TITLE_*`), the largest font size, the line spacing, and
  the colours for collections without their own.
- **`posters.yaml`**: per collection: title lines, label, icon and colours.
- **`flags/`**: full-bleed backgrounds, drawn in a 1000×1500 `viewBox`. A poster with `flag:`
  draws one under a dark fade (`#shade` in the template) so the title stays readable.
- **`art/`**: line art over the whole 1000×1500 poster, in the accent colour, chosen with
  `art:`. `tentacles.svg` is generated by `tentacles.py`; edit and rerun that instead. Use
  `title_inset:` to keep the title clear of art at the edges.
- **`logos/`**: studio logos (SVG or PNG), chosen with `logo:` and fitted where the icon goes.
  Black logos are recoloured in the accent colour; set `logo_tint: false` for logos with their
  own colours. `logos/SOURCES.md` lists where each came from; they are their studios' trademarks.
- **`icons/`**: one SVG per icon, drawn in a 100×100 `viewBox` with strokes only. The template
  sets the stroke colour and width, and shows it 600px wide.

Titles default to the collection name without a trailing "Collection". The script tries every
way to wrap the title into up to 4 lines and uses the largest font size that fits. To choose
the breaks yourself, give `title` as a list of lines.
